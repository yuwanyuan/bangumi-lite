## 新增：应用内检查更新

- 启动后自动检查 GitHub 上的**正式版 Release**，发现新版本时弹窗提示，四个选项：**立即更新 / 稍后提醒 / 跳过本次更新 / 永不检查**
  - 稍后提醒：同一版本 24 小时内不再自动弹出
  - 跳过本次更新：按版本号记住，自动检查不再提这个版本
  - 永不检查：关掉自动检查开关，仍可手动检查
- **点「立即更新」即开始下载安装**：GitHub 直链优先，连不上自动切镜像；下载完直接唤起系统安装器
- 下载失败、中断或取消都会删掉未完成的文件；下次启动也会清理上次没下完的残包，不留垃圾
- 查询走多条通道（REST API 直连 / API 镜像 / 网页跳转兜底），国内网络更容易检测到
- 设置 → 关于 → GitHub 链接下方新增「检查更新」，显示当前版本与最新版本；自动检查开关也在同一处

## 修复

- **选过背景图后固定使用深色效果**：浅色配色压在照片上要靠黑色文字描边才读得清，观感很差；现在有背景图时整套界面（含底栏毛玻璃罩色）固定走深色
- **「清除缓存」真正清掉时间线缓存**：时间线补中文名/封面用的进程内缓存以前清不掉，清完仍显示旧数据、条目点不开，现在一并清除
- **代理开关即时生效**：切换「启用代理」立刻重建客户端，不再依赖「保存」按钮
- **加载超时提示**：详情页、浏览页、收藏页超过 10 秒没有数据时提示「网络连接异常」，不再一直转圈
- 补条目数据的请求强制回源，避免端点故障期取到的空结果被缓存复用一小时
