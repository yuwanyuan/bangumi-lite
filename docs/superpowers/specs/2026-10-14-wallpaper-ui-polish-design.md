# 壁纸界面细节修复设计（2026-10-14）

## 目标

修复壁纸场景下详情页章节文字阴影、设置页二级选项面板边缘溢出与背景模糊度不生效的问题，并将“蒙版透明度”标签改为更准确的“不透明度”。

## 交互与视觉定义

- 详情页章节滑动/选择区域中的文字不显示壁纸主题添加的黑色阴影；其余详情文字保持现有策略不变。
- 设置页展开的二级选项继续使用圆角玻璃面板，但边缘裁切应完整覆盖面板内容，消除上下边缘突兀溢出的观感；不改变选项交互。
- “蒙版透明度”标签改为“不透明度”，百分比仍控制背景蒙版的不透明程度，存储字段与取值范围不变。
- “背景模糊度”滑块应控制底部玻璃层和设置页玻璃面板。底部玻璃继续使用 0–20dp 映射；面板从固定 48dp 改为按当前滑块值映射至 0–48dp。滑动完成后沿用现有持久化设置。

## 实现边界

修改限制在主题文字样式局部覆盖、设置面板布局裁切/内边距、玻璃模糊半径映射及设置标签。无需更改设置数据模型、持久化格式或导航逻辑，也不进行无关重构。

## 验收标准

1. 有壁纸时，详情章节选择区域的文字无黑色描边/阴影，其他页面仍保持现有主题表现。
2. 设置页展开的选项面板上下边缘没有内容或描边突兀溢出，圆角连续自然。
3. 背景模糊度从低值调到高值时，底部玻璃与设置面板的模糊强度均对应变化；重启/重新进入后仍使用已保存值。
4. 设置项显示“不透明度”，调整后仍按原语义保存并应用蒙版比例。
5. Android 项目构建通过；手动或模拟器验证以上四项可观察行为。

## 自审

- 未引入新的设置字段或改变旧设置的数值含义，存量用户偏好兼容。
- 模糊度的两个 UI 区域使用不同最大半径，但共享相同滑块档位；低值为无模糊、高值达到各自上限，定义明确。
- “不透明度”具体指背景蒙版的不透明比例，标签变化不改变蒙版方向、数值或 API。
- 面板边缘问题以容器裁切和内容边界为修复目标，不扩大到整个设置页的视觉重做。
