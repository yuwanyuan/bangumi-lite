# 滑动切换的过渡动画 + 每日放送页毛玻璃与滑动切换

## 目标

1. 浏览页与收藏页的左右滑动切换（以及点 tab / chip 切换筛选）目前是硬切：旧内容瞬间消失、新内容（加载屏）瞬间出现。要补一个方向感正确的过渡动画。
2. 每日放送（放送页）在有壁纸时，条目行是实心 Surface，没跟着收藏页/设置页一起做毛玻璃，整页像一块贴在壁纸上的板子。
3. 每日放送页只有点星期 tab 能切换，左右滑动无效；要支持横滑切星期，并与浏览页/收藏页同一套过渡。

## 过渡动画

- 触发来源：两页的横滑手势、类型 tab、排序 chip、收藏页的作品类型二级筛选。下拉刷新、加载更多、重试不带动画。
- **跟手**：手势期间内容按手指位移 1:1 平移（超过一屏翻页距离后按 1/4 阻尼），松手才决定切页或弹回；未达阈值、或已在序列首尾（没得切）时弹回原位，不把内容留在偏出去的位置。
- 方向：左滑（序列下一项）时旧内容向左滑出、新内容从右侧滑入；右滑反之。点 tab/chip 时方向由序列位次决定（目标位次 > 当前位次 = 向左切换），与横滑同一套判定。
  - 浏览页序列 = 作品类型 × (排名 → 热度 → 收藏)，共 15 个位置；「日期」不在序列里，从它起滑只在本类型的序列内移动（向后滑 → 排名，向前滑 → 收藏）。
  - 收藏页序列 = tab 顺序全部 6 项（全部 → 在看 → 看过 → 想看 → 搁置 → 抛弃）；作品类型二级筛选按自己的顺序算。
  - 每日放送序列 = 星期 tab 顺序。
- 形态：跟手松手达阈值后，从当前手指位置继续把旧内容推出（140ms，加速曲线）→ 此刻才换筛选（列表回顶 + 换状态）→ 新内容对齐到另一侧并滑入 + 淡入（220ms，减速曲线）。位移约屏宽 28%。
- 不做「旧出 + 新入同时可见」：换筛选那一刻旧筛选的数据已被新筛选的数据/加载态取代，要同时渲染两份列表就得让两个懒加载容器共用同一个 scroll state（会互相抢滚动位置），代价与风险不值当。
- 实现：`ui/component/FilterTransition.kt` 提供 `rememberFilterTransition()`，返回的 modifier 挂在内容容器上；位移/透明度在 `graphicsLayer` 里读取，过渡期间只重绘不重组。
- 连续快滑：同一时刻只保留最后一次切换（前一个切换任务取消），避免两段动画互相打断后停在半路；过渡进行中以「正在切过去的那一屏」为基准算方向和目标，中间的滑动不会被丢掉。

## 切换不重新加载：筛选缓存 + 相邻预取

- `ui/component/FilterPageCache.kt`：按筛选缓存第一页（收藏页 key = 状态 × 作品类型，浏览页 key = 类型 × 排序）。
- 切回已经拉过的筛选：直接给缓存，不再发请求；下拉刷新、加载更多会把新数据写回缓存。
- 落到某个筛选后后台预取左右相邻筛选的第一页，横滑过去时数据已就绪、不出现转圈；预取失败静默，真正滑过去时再按需拉。
- 同一筛选的并发请求只发一次（首拉与预取撞车时共用同一个请求）。
- 账号切换（登录/登出）后整份作废——缓存里含该账号的收藏内容。每日放送的 7 天数据本来就在同一个接口响应里，不需要这层缓存。

## 每日放送毛玻璃

- 与收藏页列表同一套：条目外层 `clip(圆角) + 半透明 surface + wallpaperGlassPanel`，内部 `SubjectListItem(transparentContainer = true)`。
- 无壁纸时 `wallpaperGlassPanel` 退化为仅裁圆角，观感与现在一致（半透明卡片）。
- 页面本身不额外整页加玻璃（与设置页一致：壁纸从页面透出，只有内容块套玻璃）。

## 每日放送左右滑动

- 序列 = 星期 tab 顺序（接口返回的星期数组），左滑进入下一天、右滑进入上一天；首尾不越界（星期一右滑、星期日左滑都不动）。
- 手势只挂在放送列表区域，不放在星期 tab 上（tab 行本身要能横向滚动）。
- 点星期 tab 与横滑走同一条路径（`selectDay`），所以也带同一套过渡动画。
- 换天时列表回到顶部：各天的条目渲染在同一个 LazyColumn 里，不显式回顶会沿用上一天的滚动位置。
- 连续快滑与另两页同样处理：过渡没走完时以「正在切过去的那一天」为基准算方向和目标，避免中间那次滑动被当成原地不动丢掉。
- 接口返回空数组时给「暂无放送数据」空状态（原先整页空白）。

## 不在范围内

- 不引入 Pager／不做跟手拖拽（手势释放后才有动画）。
- 不改数据加载、分页、缓存逻辑。
- 底栏三个页面之间的切换动画不变。

## 验收

1. 浏览页在类型/排序之间左右滑动、点击 tab 与 chip，内容都跟手并进出方向一致；收藏页同样，且「在看」可由滑动进入。
2. 收藏页在状态之间滑动、点 tab、点作品类型筛选同样有动画；「日期」等非序列位置切换后位置正确。
3. 连续快速滑动不会停在偏移状态（最终内容居中、不透明度 1）；未达阈值或首尾边界时弹回原位。
4. 切回看过的筛选直接出内容，不出现转圈、不重新请求；左右相邻筛选提前预取。
5. 每日放送页在有壁纸时条目行呈现毛玻璃，与收藏页一致；无壁纸时外观不变。
6. 每日放送页左右滑动可切星期并跟手，方向与手势一致；首尾不越界；换天后列表在顶部。
7. 构建通过，并在模拟器上确认。
